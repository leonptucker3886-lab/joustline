# Designer SOP v1.0 (Joustline)
Ratified 2026-10-19. Source of truth: `Team_SOPs_v1.0.pdf` in this folder. Supervisor for this repo: 2nd LT Real.

## Approval
A doc is **Approved** only when the reviewer and Leon both sign off. Scope, assets and dependencies must be clear first.
If the reviewer doesn't respond within 2 working days, it goes to Leon and his sign-off alone is enough.
Any change after approval needs another review. Versioning: +0.1 small change, +1.0 scope change.

## QA checklists
Sent when a build is marked 'Ready for QA'. Each names a Design owner. Every item lists:
feature or area, steps to test, expected result, known issues, target platforms.
Joustline checklists live in `docs/qa/`.

## Feedback triage
Every Monday; post each result with its reason in the topic thread.
If 3 or more testers report the same item, review it within 24 hours.

## Balance log
One shared log: old value, new value, rationale, build number. Joustline's is `docs/BALANCE_LOG.md`.

## Cut features
Mark the doc 'Cut' with a reason and keep it.
